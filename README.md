# Det Danske Alfabet

("The Danish Alphabet")

## Type a letter, hear it spoken

https://rvedotrc.github.io/det-danske-alfabet/index.html

(or just open [index.html](index.html))

Press a letter to hear it spoken. You can switch between the three voices by clicking on the avatars.

## Hear it spoken, type the letters

Simple game (of sorts) in an infinite loop.

The computer selects a random letter, or a perhaps a short sequence of random letters, then it speaks them using the selected voice. You then have to type in what letters you heard.

If you get the correct answer, then a Dannebrog is shown in celebration: 🇩🇰

Press "Hva'?" ("Pardon?"") to have the letters re-spoken.

Press "Jeg giver op!" ("I give up!") to have the answer shown to you.
